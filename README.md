# Clomosy Lab Management System

Clomosy Lab Management System is a desktop automation project developed with Clomosy.  
The project is designed to manage basic laboratory operations through separate admin and customer panels.

## About the Project

This system includes user registration, customer login, admin login, product/service management, and panel-based navigation.  
The main goal of the project is to create a simple but functional lab management automation system with a clear interface.

## Features

- Customer registration system
- Customer login panel
- Admin login panel
- Separate customer and admin screens
- Service/product listing
- Search area
- Repair/waiting status management
- Back navigation between pages
- User-friendly button design
- Icon-based interface elements

## Technologies Used

- Clomosy
- SQLite
- Desktop UI components

## Project Purpose

The purpose of this project is to practice desktop automation development, database usage, user login systems, and panel-based application design.  
It was developed as a student project to improve software development and interface design skills.
