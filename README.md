# Clomosy Lab Management System

Clomosy Lab Management System is a simple laboratory management system developed with Clomosy.

The project includes general login, admin login, customer registration and customer login screens. It was created as a basic role-based automation example.

## Features

- General login screen
- Admin login screen
- Customer registration screen
- Customer login screen
- Simple role-based structure
- Form-based interface design

## Technologies Used

- Clomosy
